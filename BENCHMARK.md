# BENCHMARK.md -- external opponents (the scrimmage-ladder proxy)

Battlecode 2021 bots published on GitHub, used as opponents so that progress is
measured against code written by other people, not only against our own
lineage. This is the closest available substitute for a live scrimmage ladder.

## Rules (binding, from the project owner)

1. **Never read their source.** No `cat`, `grep`, `head`, editor or `Read` on
   any file under a benchmark repo except scaffold metadata (`version.txt`,
   `gradle.properties`, `build.gradle`, `README`) and directory listings.
   Compilation goes through `tools/bench-compile.sh`, which writes compiler
   diagnostics to a log file and prints only counts.
2. **No game against a bot may be reviewed until we beat it at least 20% of the
   time** on a full-corpus evaluation (both sides). "Reviewed" means any
   replay, trace, log, board or per-game reason. Until then, only the score.
   The gauntlet keeps losing replays, so the discipline is on the reader:
   check the bot's tier in the table below before opening anything.
3. Their stdout is silenced in every game (`bc.engine.silence-*`).

## Where they live

Repos are shallow-cloned under `~/projects/vibe/bc21-benchmarks/<owner>_<repo>`
(outside this git repo; nothing of theirs is committed). Compiled classes go to
`_classes/<owner>_<repo>/`, one directory per repo so package names cannot
collide. `manifest.tsv` maps an opponent name `<owner>.<package>` to
(package, classdir, repo, commit). `tools/gauntlet.sh` resolves opponent names
through the manifest.

Selection of the "final" bot per repo is by **directory name only** (names
like `finals`, `quals`, `sprint2`, `vN`): where a repo holds many versions we
keep them all as rungs, since a team's own version history is a natural ladder
of increasing strength.

## Tiers

| tier | our win rate | access |
|---|---|---|
| locked | < 20% | score only |
| target | 20-50% | replays may be reviewed; primary loss source |
| peer | 50-90% | regression check |
| solved | > 90% twice | leaves the gate, stays in the roster |
